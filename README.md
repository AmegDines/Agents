# Agents

This repository is a collection of various AI agents, workflows, and experimental implementations designed to automate specific tasks and domains.

---

## 📁 Included Projects

* **AssignmentTracker** — Tools and logic for tracking and managing academic or work assignments.
* **Exam Rescheduler** — An automated assistant to help manage and reschedule exam dates and resolve scheduling conflicts.
* **HF Code agent Practise** — Practice workflows, experiments, and code implementations built using Hugging Face's Agent frameworks.
* **Interview assistant agent** — An AI-powered assistant designed to support interview preparation and interactions.
